# محل قرارگیری فونت‌های دانا (Dana Fonts)

فایل‌های فونت دانا را دقیقاً در همین پوشه کپی کنید:

- `Dana-Regular.woff2` (یا `Dana-Regular.woff` یا `.ttf`)
- `Dana-Medium.woff2` (یا `Dana-Medium.woff` یا `.ttf`)
- `Dana-Bold.woff2` (یا `Dana-Bold.woff` یا `.ttf`)

در صورت استفاده از فرمت TTF یا WOFF، فایل `src/index.css` تمامی فرمت‌های استاندارد را به طور خودکار لود می‌کند.
